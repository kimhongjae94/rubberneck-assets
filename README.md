# RUBBERNECK — character models

Game-ready character models for the browser game **RUBBERNECK**. The game loads them at runtime through jsDelivr:

```
https://cdn.jsdelivr.net/gh/kimhongjae94/rubberneck-assets@v1/models/<name>.glb
```

- Format: glTF binary (`.glb`), meshopt-compressed geometry (`EXT_meshopt_compression`, `KHR_mesh_quantization`), WebP textures (`EXT_texture_webp`), MakeHuman "default" skeleton.
- Every model is under 1 MB.
- Built with Blender + MPFB from the MakeHuman base mesh and the MakeHuman system assets, all **CC0 1.0** (public domain). See [ASSETS.md](ASSETS.md) for what each model is made of.
